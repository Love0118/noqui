재생 가능 수는 재시작 후 인증된 `/internal/v1/playlists` 응답과 일치한다. 한국어 이름 보완 항목은 기본 검토 대기와 별도로 관리하며 일부 겹친다. 모든 한국어 제목·별칭 검토가 끝난 상태는 아니다. 팝의 Believer·Teeth는 작가 크레딧 불일치로 보류했다. ZEOM의 보류 37곡도 재생에서 제외했다.

Chrome의 실제 YouTube 검색 결과와 영상 설명을 근거로 68곡의 녹음을 교체하고 별칭 근거186건, 이름·태그·검수 변경283건을 반영했다. 직접 번역하거나 추측한 음차는 추가하지 않았다. 씹노퀴의 기존 선택541곡 ID와 순서를 보존했다. 국내28번은 윤종신의 정식 발매 Live 녹음이며 스튜디오 버전으로 표기하지 않았다. 534번 보컬로이드 곡은 Hatsune Miku 원곡 자막 영상과 Madaco 크레딧을 확인했다.

운영 파일은 `/var/lib/noqui/library`의 다섯 목록뿐이다. 전체 길이48kbps 스테레오 Ogg Opus이며 정답 메타데이터를 제거했고, 기존5GiB 임시 캐시 계산에서 제외한다. 준비본 디렉터리를 같은 파일시스템에서 이동하여 설치 중 음원 복사를 만들지 않았다.

이전 라이브러리와 이전 두 정제 준비본, 최초 설치 번들, ZEOM 다운로드·중간 작업 음원을 제거했다. 하드링크가 있어 파일 크기의 합계 대신 실제 여유 공간 차이를 측정했다. 정리 직전1,551,753,216바이트에서 정리 후3,189,731,328바이트로 늘어 **1,637,978,112바이트(약1.64GB)**를 확보했다. 사용자 업로드 음원·운영 DB·월드·플레이어 데이터·전체 서버 백업은 유지했다. 상세 삭제 경로와 응답은 [설치 영수증](20261028-playlist-refresh.json)에 기록했다.

백엔드는 성공한 CI 릴리스 `c6589f1aeb2d47a039903ac6e09ee77650181eed`를 `/opt/noqui/releases/20261028-playback-c6589f1`에 설치했다. 릴리스 압축파일 SHA-256은 `ca1d534c1f72bfb5affce328614a67ec3814d342ec3d81c20ff9da831d0e862d`, 플러그인은 `77c2d6634023db4ecc720ffd5b697b58ebe4b9d71cd51b15a5653fd875ac2cad`다. 310초 이상 음원의 버퍼 보고 거절, 과도한 재생 상태 방송, 미확인 재생 건너뛰기 시 라운드 감소 수정본이 이제 실행 중이다. 기존 브라우저 탭은 새로고침해야 한다. 실제 참가자의 전체 게임을 이번 배포에서 다시 실행한 것은 아니다.

사전 검사에서 다섯 원본 목록의 음원 검사, 보컬로이드 검사, 내보낸 파일의 해시·전체 길이·정답 태그 제거, 두 SQLite DB의 무결성과 외래키 검사,541곡 선택 보존을 확인했다. Windows에서 열려 있는 DB의 재생성 실패를 재현해 SQLite backup 방식으로 갱신하도록 수정했다. 배포 후에는 서비스 상태, 웹 healthz, 플러그인 기동과 다섯 목록의 실제 API 응답을 확인했다.

통합 DB는 [playlists/catalogue.sqlite3](../playlists/catalogue.sqlite3), 곡별 조사 근거는 [검색 조사 기록](../catalogues/youtube-jamm-research-20261028.json)에 있다. JSON이 원본이며 DB를 직접 고쳐도 재생성 시 덮어쓴다.
