출제 대상의 표시 제목은 출처에서 실제 사용된 한국어 통용 제목·발음 또는 공개된 숫자 제목입니다. `2002`, `1925`, `『±0』` 같은 제목에 임의의 한국어 읽기를 만들지 않았습니다. 한국어 태그만 있고 표시 제목이 영문인 항목, 실제 사용 근거를 확인하지 못한 이름은 검수 완료로 계산하지 않습니다. 검수 대기곡은 원제와 조사 이력·음원을 보존한 채 `excludedSongs`에 사유를 기록합니다. 기존 곡 정체·작가 검토 보류는 한국어 이름이 확인되어도 해제하지 않았습니다.

8개 Luna 조사 배치를 메인 세션에서 다시 검토하고, 인용이 일치하지 않은 사례는 2개 추가 배치와 메인 조사로 확인했습니다. 실제 페이지·영상 제목·설명·PDF를 대조했습니다. 단순 검색어, 동명 다른 곡, 작가와 가수의 혼동, 자동 번역 페이지, 곡명과 무관한 한국어 접두어는 승인 근거로 사용하지 않았습니다. `I=Fantasy`의 잘못된 제안 `전 = 판타지`는 기사에서 확인한 `아이=판타지`로 수정했습니다. 원곡 제목을 잘못 `Mili`로 저장한 항목도 동일 영상의 `유토피오스피어`로 바로잡았습니다.

`originalTitle`, `namingHistory`, `retiredAliases`에 이전 표기를 보존했습니다. 원어 작가 크레딧과 가수, 곡 UUID·영상 ID·원래 순서·녹음 버전은 변경하지 않았습니다. 외부 근거가 없던 과거 발음 제안은 검색 근거로 취급하지 않으며, 이번에 교정한 항목에서는 `retiredAliases`로 옮겼습니다. 특수문자 제거 태그는 표시 제목과 별도로 기록합니다. 태그는 최대 10개·각 32자와 게임의 정규화 중복 제한을 만족합니다.

[통합 DB](../playlists/catalogue.sqlite3)의 `플레이리스트`, `재생가능곡`, `검토필요곡`, `이름검토필요곡`, `별칭목록`, `출처목록` 뷰가 동일한 검수 기준을 사용합니다. 씹노퀴의 별도 DB와 내부 API import 배치도 함께 갱신했습니다. [기계 판독용 검수 기록](20261110-korean-playlist-review.json)에 배치 해시, 메인 판단, 개별 출처, 변경 전후 이름을 남겼습니다.

전체 6개 원본 카탈로그의 음원 해시·파일 크기·전체 길이·내장 제목·작가를 검사했습니다. 태그를 수정한 348개 실제 파일은 `OpusTags`를 제외한 길이 구분 Opus 패킷 SHA-256과 패킷 수가 수정 전후 동일합니다. 새 서버 번들의 1,590개 출제 항목도 해시·전체 길이·정답 코멘트 제거를 확인했습니다. 모든 녹음을 직접 청취했다는 의미는 아닙니다. 관련 회귀 테스트 15개를 통과했습니다.

라이브 적용은 기존 음원 파일과 오디오 식별자를 유지하는 메타데이터 교체 방식입니다. 퀴즈가 끝난 상태에서만 적용하며 Minecraft 프로세스와 진행·점수를 강제 초기화하지 않습니다. 전체 선택 수와 기본 셔플, `/noqui limit <라운드 수>`, 5 GiB 임시 캐시에서 설치 음원을 제외하는 동작은 유지합니다. 적용·비공개 재생 페이지 검사 결과는 기계 판독용 기록의 `live` 항목을 기준으로 확인하세요.
