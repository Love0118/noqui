# 2026-10-28 영어 제목 한국어 발음 태그

사용자가 `스피치리스`, `러브스토리`처럼 일반적인 한국어 발음 표기를 추가하도록 승인했다. 영어 제목 후보를 여덟 Luna 작업으로 나누었고, 한 작업은429 오류로 종료되어 부모가 처리했다. 제안을 검토하고 형식을 정리해 전체 정제 데이터162개 곡 항목에 별칭164개를 추가했다. 로마자로 적힌 일본어 제목5개는 통용 한국어 이름 조사 대상으로 남겼다. 가운데점이 있는 `F・L・Y`도 포함했다.

일반 발음은 `origin: user_authorized_pronunciation`으로 구분한다. 외부 검색 인용으로 표시하지 않으며 원제와 작가 크레딧을 보존했다. 원본 Ogg Opus의 `ANSWER_TAG`, import 입력, 서버 플레이리스트와 두 SQLite DB를 갱신했다. 태그10개 제한에 걸리면 원제와 동일한 중복 태그를 제거하되 원제 자체의 정답 판정은 유지한다. `REDRED`는 `마틴`을 유지하고 중복 작가 별칭 `MARTIN`을 태그에서 제외했으며 원래 작가 목록은 유지했다.

기존 선택곡과 기본 검수 상태는 유지했다. 운영에 포함된136개 곡의 태그가 변경되었고, 나머지26개는 기존 보류곡의 정제 원본에만 반영했다. 전체1,091개 재생 항목을 내부 API로 조회해 로컬 목록과 일치함을 확인했다. `Speechless`의 `스피치리스`, `Love Story`의 `러브스토리`도 실제 응답에 포함되었다. 오디오 서비스만 재시작했고 Minecraft PID1561884와 음원 파일은 유지했다. 새 플레이리스트 시작부터 변경된 태그를 사용한다.

다섯 목록의 원본 음원·해시·태그 검사와 보컬로이드 검사, SQLite 무결성·외래키 검사, 검증기의 일반 발음 허용 및 출처 없는 작가·가수·미분류 별칭 거절을 확인했다. 이름 보완 대상은180개에서53개로 줄었으며 남은 항목에는 일본어 제목과 가수 별칭이 포함된다.
