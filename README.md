# Noqui 1.0.4

Paper 26.3 / Java 25용 노래퀴즈 플러그인입니다. 오디오는 Rust 서비스가 처음 115초(짧은 곡은 전체)를 약 48kbps Ogg Opus로 캐시하고 브라우저가 재생합니다. 게임·출제권·정답·점수는 Paper가 결정합니다.

## 빌드

저장소 루트에서 순서대로 실행합니다.

```powershell
python noqui/lobby-assets/build_pack.py --check
python noqui/lobby-assets/test_pack.py
mvn -B -ntp -f noqui/plugin/pom.xml clean install
mvn -B -ntp verify
cargo test --locked --manifest-path noqui/web/Cargo.toml
```

산출물은 `noqui/plugin/target/noqui-plugin-1.0.4.jar`, `target/mc-luck-defense-1.0.29.jar`입니다. Moma는 Noqui API에 provided 의존성을 사용하며 API는 Noqui JAR에만 포함됩니다. Noqui 없이 Moma만 기동하는 경로도 유지합니다. 두 플러그인을 함께 교체한 뒤 정상 재시작합니다. Moma 런타임 재로드는 매번 현재 서비스 제공자를 조회합니다.

팩의 소스와 생성·검증 방법은 [로비 에셋 안내](lobby-assets/README.md)를 따릅니다. 검증한 `noqui/lobby-assets/lobby-pack.properties` 하나만 JAR 루트에 포함하며 ZIP은 포함하지 않습니다. 팩 ZIP을 해당 내용 해시의 공개 URL에 먼저 게시한 후 플러그인을 기동합니다. 기존 `plugins/Noqui/lobby-pack.properties`가 있으면 자동 덮어쓰지 않으므로 팩을 바꿀 때 검증한 새 descriptor를 함께 반영합니다. CI는 Python 표준 라이브러리로 팩 재현성과 descriptor를 먼저 확인한 뒤 Maven을 실행합니다.

## 설정과 이용

정제된 `noqui_cabin` 월드를 서버 정지 중 반입합니다. 기본 스폰은 `(411.5, 11, -205.5)`, 경계 중심은 `(416, -192)`, 크기는 250입니다. 바깥 청크는 void generator를 사용하며 스폰 안전성과 월드 보호를 적용합니다.

`plugins/Noqui/config.yml`의 bridge 주소는 루프백 `http://127.0.0.1:8788`, 공개 주소는 `https://noqui.danta.qzz.io`입니다. `bridge.secret-file`에는 Rust와 같은 32바이트 키 파일 또는 64자리 16진수 키 파일을 지정합니다. 실제 키·`songs.yml`·`credits.json`은 비공개 서버 데이터입니다. 웹 설정은 `deploy/`를 따르며 Minecraft 주소는 `mud.danta.qzz.io`입니다.

OP 명령은 `/noqui start [rounds]`, `limit <rounds>`, `stop`, `skip force`, `hint`, `pause`, `resume`, `give <player> [amount]`, `status`, `admin`입니다. 일반 참가자는 `/noqui`로 메뉴를 열고 `/noqui skip`으로 투표하며 `/noqui bgm`으로 BGM을 켜거나 끄고 `/noqui leave`로 퀴즈에서 나갑니다. `/noqui start`는 무제한, `/noqui start 200`은 최대 200라운드입니다. `/noqui limit 0`으로 무제한 전환하며 양의 정수로 실행 중 제한을 바꿉니다. 이미 시작한 라운드보다 낮은 양수 제한은 거절하고, 남은 제한을 초과한 대기 곡은 취소·반환합니다. 콘솔은 접속자가 없어도 시작할 수 있습니다.

퀴즈 시작 시 활성 디펜스·관전 세션이 없는 접속자는 cabin으로 안내합니다. 디펜스·관전은 현재 위치에서 동시에 참여합니다. Moma에서는 퀴즈가 진행 중일 때만 보호된 `노래퀴즈` 아이콘 하나가 표시됩니다. 로비는 3번 칸, 게임·관전은 4번 칸이며, 수량은 출제권 보유량에 맞춰 최대 64개로 표시하고 설명에 정확한 장수를 적습니다. 0장도 아이콘은 남습니다. 우클릭 메뉴는 `로비`와 `출제`뿐입니다. 로비 이동은 기존 세션 나가기 잠금·정리 절차를 따르며, 출제는 진행 중인 게임을 유지합니다. 두 로비의 `미니게임` 나침반은 기존 참가·관전 메뉴를 엽니다. cabin의 F키는 기본 보조 손 교환이며 Moma의 기존 F 메뉴는 유지합니다.

브라우저 연결 창은 퀴즈 참가자에 대해 웹 서비스가 최근 연결 끊김을 확인한 경우에 자동으로 열립니다. 오디오 준비 상태와 브라우저 접속 상태는 별개이며, 서비스 장애나 오래된 응답은 연결 끊김으로 취급하지 않습니다. 출제 입력 창·상점 등 다른 화면을 덮지 않고, 연결되면 자신의 연결 창만 닫습니다. 다시 표시하기 전에는 유예 시간을 둡니다. 명시적으로 퀴즈에서 나간 사람은 자동으로 재참가시키지 않습니다. F키와 제어 종이의 브라우저 기능은 제거했습니다. 수동 복구는 `/noqui connect`, 제출 취소·넘기기 투표는 `/noqui`를 사용합니다. cabin 출제권은 손에 들고 우클릭하며, 인벤토리 안에서는 일반적인 이동·분할·보조 손 교환이 가능합니다.

실물 출제권은 cabin 안에서만 보유 잔액에 맞춰 표시합니다. Moma 로비·게임에는 실물 출제권 대신 위의 보호된 대리 아이콘만 표시하며, 퀴즈가 꺼지면 아이콘도 사라집니다. `/noqui give <nickname>`은 기본 1장, 한 번에 1..1000장을 영구 장부에 지급합니다. 오프라인이거나 인벤토리가 가득 찬 경우 지급을 보류하고 공간이 생기면 다시 전달합니다. 출제권을 떨어뜨리면 소유 잔액을 즉시 차감하고 고유한 지상 수령권으로 전환합니다. 다른 플레이어가 주우면 한 번만 이전하며 공간이 일부만 있으면 나누어 줍습니다. 오래된 아이템 복사본, 재접속과 인벤토리 복원으로 잔액이 늘어나지 않습니다. 떨어진 아이템의 자연 소멸·파괴는 원래 잔액으로 환급하지 않습니다. 장부 v2는 기존 v1 잔액·예약·구매 영수증을 보존합니다. 지상 위치·나이는 30초마다 한 번에 저장하고 소유권 변경은 즉시 저장합니다.

라운드는 기본 무제한이며 명령으로 0(무제한) 또는 최대 2,147,483,647까지 제한합니다. 유효한 제출을 수락할 때 출제권 한 장을 소모하며, 입력 창 취소·유효하지 않은 입력에는 소모하지 않습니다. 재생 전 취소·이탈·준비 실패·종료는 한 번만 실물로 반환하고 실제 재생 시작 때 사용을 확정합니다. 입력 중 다른 라운드나 지급이 진행되어도 같은 퀴즈·회원권에서 현재 자격을 다시 확인하며, 이전 퀴즈 입력 창은 사용할 수 없습니다. 한 사람당 재생 전 한 곡, 전체 최대 64곡을 수락 즉시 미리 변환합니다. 장기 변환 대기열은 64×300초와 15분 여유의 유한 예산으로 보호하며 기존 15분 만료로 정상 대기 곡을 버리지 않습니다. 변환된 곡은 브라우저가 없더라도 조용히 보존하고, 준비된 브라우저가 생기면 전달 여유 1초와 3·2·1 카운트다운을 거쳐 재생합니다. 정답 접수는 웹이 해당 예약을 수락한 뒤 시작합니다. 준비 실패는 라운드를 소비하지 않으며 마지막 라운드는 5초 공개 뒤 종료합니다. `round-seconds`는 1..115이고 실제 오디오 길이를 넘지 않습니다.

제목·태그는 대소문자/공백/기호를 무시한 부분 문자열로 판정합니다. 출제자는 자기 곡에서 득점할 수 없습니다. 최초 정답자만 득점하며 경쟁 점수는 정답당 1점입니다. 별도의 영구 정답 포인트는 기본 1이며, `title-bonus: true`이면 제목을 맞힌 경우 2를 받습니다. 같은 라운드·UUID 보상은 한 번만 지급됩니다. 점수·정답 포인트·출제권·별빛은 각각 분리됩니다. 기본적으로 첫 정답 후에도 곡을 계속 재생하고 `match-skip: true`이면 즉시 5초 공개로 넘어갑니다. 참가자 스킵은 현재 참가자의 엄격한 과반수, UUID당 라운드별 한 표이며 이탈 시 다시 계산합니다. OP만 강제로 넘길 수 있습니다.

일시정지는 재생 위치·남은 시간·힌트 시간을 고정하고 정답을 받지 않습니다. 재개는 같은 위치에서 새 카운트다운으로 시작합니다. 최초 힌트는 원문 한글 초성과 영문/숫자의 밑줄이며, 이후 무작위로 약 25%씩 공개하되 최소 한 글자를 남깁니다. `auto-hint: false`가 기본이고 true이면 재생 중 9초마다 진행합니다.

cabin의 전체 인벤토리는 바깥 Moma 인벤토리와 별도로 영구 보관합니다. 일반 아이템·가젯·방어구·보조 손·커서와 칸 배치는 퇴장·종료·접속 종료·디펜스 전환 전에 저장하고 다음 입장 때 복원합니다. 출제권은 저장된 복사본을 영구 장부와 대조하며 가젯은 고유 일련번호를 검증하므로 이미 사용하거나 떨어뜨린 아이템이 다시 지급되지 않습니다. 퀴즈 입장 때 원본 BGM 설정을 저장하고 OFF로 시작하며 `/noqui bgm`으로 변경합니다. BGM은 실제 Moma 참가·관전 세션의 재생 목록에서만 재생하고 cabin에서 기본곡을 자동으로 틀지 않습니다. 퀴즈 이탈은 원본 설정을 복원합니다.

`quiz-active`가 true였던 정상 재시작은 `quiz-limit`에 저장된 제한으로 새 제출 대기 상태를 만듭니다. 이전 곡·타이머·작업·브라우저 회원권은 재사용하지 않습니다. 점수는 한 실행에 한정되며 출제권 잔액과 개인 제출 기록은 보존합니다.

## 별빛과 상점

`/money`는 내 별빛 ✦와 정답 포인트를 보여 줍니다. 실제 디펜스 참가자가 100라운드 단위 체크포인트 k에 도달할 때마다 즉시 10×k 별빛을 받습니다. 누적 지급량은 10×k×(k+1)/2이므로 99R=0, 100R=10, 200R=30, 300R=60, 1000R=550입니다. 건너뛴 체크포인트도 모두 따라 지급하고, 세션 UUID·플레이어 UUID·체크포인트 거래 ID로 종료·퇴장·접속 종료·리로드의 중복 지급을 막습니다. 관전자는 받지 않습니다. `rewards.yml`의 새 공식은 `milestones-v1`이며 이전 `starlight-per-round`는 무시합니다. 기존 지갑 잔액과 이미 저장된 이전 지급 의무는 원래 거래 ID로 보존합니다. 미저장 보상은 리로드를 막고 저장·전달 대기열에서 재시도합니다.

cabin의 상점 NPC 상자 GUI에서 구매합니다. 치장과 가젯은 별빛 또는 정답 포인트로 살 수 있으며 기본 가격은 1포인트=10✦ 비율입니다. 출제권은 10✦ 전용, 치장·삼단 점프는 20✦ 또는 2포인트, 사단 점프·중력은 40✦ 또는 4포인트, 망치·눈덩이는 10✦ 또는 1포인트입니다. 치장은 두 게임에서 표시하며 가젯과 이단 점프는 cabin에서만 적용합니다. 구매 내역과 출제권 지급은 각 저장소의 동일 거래 ID로 재시도해 재시작 후 중복 지급을 막습니다. 리소스팩 URL·해시·가격과 로비 기능은 `lobby` 설정 및 별도 팩 자료를 따릅니다.

## 검증

Maven 검사는 크레딧 예약/확정/반환/재시작, 유한 라운드, 투표, 일시정지와 힌트, 비동기 취소, HUD 복구, 동시 참여, BGM 복구, HMAC 실제 HTTP 요청, 공개 전 정답 비노출을 포함합니다.

승인된 Paper 파일·EULA·정제 월드가 있을 때 격리된 fixture를 실행합니다.

```powershell
mvn -B -ntp -f noqui/plugin/pom.xml dependency:build-classpath -Dmdep.outputFile=target/smoke-classpath.txt
python noqui/plugin/smoke/run_paper_smoke.py
```

fixture는 `.runtime/noqui-plugin-smoke-*` 안에서 Paper를 두 번 부팅해 월드·스폰·경계, 네이티브 연결 창, 서비스 등록, 빈 서버 시작/종료, Moma 런타임 교체와 활성 상태 재시작을 확인합니다. 실제 클라이언트 화면과 브라우저 청취는 별도 검증 대상입니다.
