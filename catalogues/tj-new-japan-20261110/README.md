# TJ 일본 신곡 150 - 261110

2026년 11월 10일 기준 TJ 일본곡 분류의 최신 등록곡 150개입니다. TJ 등록일 내림차순, 같은 날은 TJ 번호 내림차순으로 정렬했습니다. 선정 범위는 2026-11-10부터 2026-04-28까지이며 원곡 발매일 기준의 신곡 목록과는 다릅니다. 게임을 시작하면 기존 방식대로 셔플합니다.

한국어 표시 제목 150개와 전체 길이 음원 150개를 확인했습니다. 작가의 한국어·원문 이름 연결까지 확인한 139개를 서버 번들에 포함합니다. 나머지 11개는 일부 공동저작자 이름의 사용 근거가 부족해 검토 대기로 남겼습니다. 근거가 없는 일본어 음차는 추가하지 않았습니다. 영어 제목의 발음 대체는 사용자에게 허용받은 범위로 기록합니다.

`モエチャッカファイア`는 **차가운 상어 아가씨**, `あぶく`는 **물거품**, `mosi mosi?`는 **여보세요?**처럼 검색에서 확인한 한국어 이름을 우선합니다. 제목·작가의 별칭에는 출처와 확인 문구를 보관합니다. 사용자가 직접 지정한 `DECO*27 → 데코`는 외부 검색 출처와 구분합니다.

## DB 보기

`catalogue.sqlite3`에서 다음 뷰를 열면 됩니다.

- `이중언어곡목록`: 한국어 제목, 원제, 가수와 작가의 한국어·원문 이름, TJ 등록일과 번호, 검토 상태.
- `태그목록`: 특수문자를 제거한 게임 정답 태그.
- `별칭목록`: 곡명·작가·가수 별칭과 사용 근거.
- `출처목록`: 곡별 확인 출처.
- `검토대기곡`: 확인하지 못한 작가 표기와 구체적인 보류 사유.

```sql
SELECT * FROM 이중언어곡목록 ORDER BY 번호;
SELECT * FROM 검토대기곡 ORDER BY 번호;
```

작사·작곡은 원문 크레딧을 따로 보존합니다. `倍倍FIGHT！`의 TJ 원문 크레딧은 공식 아티스트 발매 정보와 달라 작사·작곡을 `玉屋2060%`로 정정했습니다. 정정 근거와 TJ 원문은 `credit-corrections.json` 및 각 곡의 `officialCredits`·`creditCorrection`에 남겼습니다. `香水`의 `8s`는 공식 크레딧이 확인되므로 임의로 가수 이름으로 바꾸거나 한국어 발음을 만들지 않았습니다.

## 파일과 음원

- `catalogue.json`: 150곡의 정제 결과와 근거.
- `source-selection.json`: TJ 원제·가수·작사·작곡·등록일·일본곡 분류 확인 URL.
- `review-required.json`: 출제에서 제외한 11곡.
- `summary.json`: 이름·음원·출제 가능 곡 수.
- `audio/`: 전체 길이 48 kbps, 48 kHz 스테레오 Ogg Opus. 한국어 제목·작가·정답 태그를 내장하며 Git에는 포함하지 않습니다.

스토리 MV, 라이브, 커버, 반주, 단축 버전 대신 정규 음원·Topic·원곡 자막 음원을 선택했습니다. 서버용 [번들](../../playlists/tj-new-japan-20261110/)은 정답이 든 오디오 태그를 제거하고 전체 음원 길이를 유지합니다. 운영 중 재생 구간은 기존 메모리 처리 방식을 사용하며 잘린 파일을 따로 만들지 않습니다.

일본어 원제와 작가 태그 및 최대 16개 태그를 지원하는 Paper와 web 버전을 함께 사용해야 합니다. 이 작업은 프로젝트에 저장한 것이며 라이브 서버에는 설치하지 않았습니다.
